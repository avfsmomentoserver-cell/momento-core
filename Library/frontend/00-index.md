# Frontend Overview

## Technology Stack
- **Framework**: React 18+ with TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand/Redux Toolkit
- **Real-time**: WebSocket hooks
- **Charts**: Recharts/D3.js
- **Testing**: Jest, React Testing Library, Playwright
