# Component Library

## Core Components
- MarketChart - Candlestick/volume visualization
- PatternViewer - DNA pattern display
- PressureLadder - Mega pressure tracker
- InsightCard - Market insight display
- BacktestResults - Performance metrics table

## Design Principles
- Accessibility first (WCAG 2.1)
- Responsive design
- Dark/light theme support
- Consistent spacing (8px grid)
